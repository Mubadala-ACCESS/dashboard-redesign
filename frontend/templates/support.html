How to use the dashboard

A guided overview for public users, analysts, and deployment teams.

Quick workflow

  1. Start on the map and filter by privacy, device type, or station status.
  2. Open a marker popup to view metadata or move to the station detail page.
  3. Use Quick View for interpreted conditions and Advanced Analysis for exports and trend work.

Research workflow

  1. Select display period and aggregation.
  2. Choose metrics and enable individual sensor readings when needed.
  3. Export the exact view as CSV or JSON, or open the printable report for review packages.

Operational notes

The backend caches filter sets, station summaries, metadata, and network alert rollups to reduce repeated Mongo reads. Recommended Mongo indexes and the long-term PostgreSQL replacement schema are included in the deployment package.
