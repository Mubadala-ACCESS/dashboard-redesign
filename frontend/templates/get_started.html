Get Started

Use the dashboard in two steps

Start on the map to find a station, then open Quick View or Advanced analysis for station-level detail. This page also keeps the key glossary notes close at hand.

1. Use the map

  1. Search by station name, number, or station ID.
  2. Filter by privacy, device type, and status using the left panel.
  3. Click a station marker to open the right-side quick view panel.

2. Open station views

  1. Quick View gives the latest interpreted readings.
  2. Advanced shows charts, aggregation, exports, and sensor split mode.
  3. Metadata explains available parameters and instrument definitions.
